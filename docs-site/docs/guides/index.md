# Guides pratiques

Des scénarios courts, orientés "comment faire X", pensés pour quelqu'un qui découvre une fonctionnalité précise plutôt que pour qui cherche une référence exhaustive (voir [Référence](/reference) pour ça).

Cette section se construit lot par lot, au fil des fonctionnalités livrées par le chantier v8.0. Scénarios identifiés, pas encore rédigés :

- **Ajouter son premier middleware** (PSR-15, LOT 6) — la pile de middlewares est une pure addition, inutilisée par défaut : bon premier exemple d'extension sans rien casser.
- **Utiliser le conteneur PSR-11** (LOT 5) — résoudre un service, l'injecter dans un contrôleur.
- **Brancher un logger PSR-3** (LOT 5) — remplacer ou étendre l'adaptateur de log par défaut.
- **Nommer et organiser ses entités avec les namespaces** (LOT 1/9) — convention `src/<app>/<Module>/Entity`, alias générés.
